# eccodes-sys

Low-level Rust bindings to ECMWF's [ecCodes](https://github.com/ecmwf/eccodes) C library.

This crate provides raw FFI bindings generated by [bindgen](https://github.com/rust-lang/rust-bindgen) from `eccodes.h`. For a safe, ergonomic API, use the higher-level `eccodes` crate (planned).

## Features

### Build strategy (mutually exclusive)

- `vendored` - Build ecCodes (and libaec for AEC compression) from source.
- `system` - Link against system-installed ecCodes.

`vendored` is enabled by default.

### Format support (enabled by default)

- `product-grib` - GRIB format support.
- `product-bufr` - BUFR format support.

### Geospatial (enabled by default)

- `geography` - Geographic support (projections, coordinates).

### Compression codecs (enabled by default)

- `aec` - AEC compression support.
- `jpg` - JPEG2000 compression support.

### Compression codecs (off by default)

- `png` - PNG compression support.

### Additional features (off by default)

- `netcdf` - NetCDF format support (requires NetCDF library).
- `memfs` - Bake the eccodes definition/sample tables into `libeccodes` itself
  (`ENABLE_MEMFS=ON`). With this on, end users do **not** have to ship an
  `eccodes_resources/` directory. Build-time requirement: Python 3 must be on
  `PATH`.

### Threading (mutually exclusive, off by default)

- `eccodes-threads` - POSIX threads support.
- `eccodes-omp-threads` - OpenMP threads support.
